# Romantik Soru Sitesi

GitHub Pages için hazırlanmış tek sayfalık romantik mini site.

## Dosyalar
- `index.html` — site
- `final-fotograf.jpeg` — final sayfası görseli
- `papatyali-fotograf.jpeg` — “Biraz kötüyüm” bölümündeki fotoğraf
- `playlist-gorsel.png` — Spotify playlist kartı görseli

## Yayınlama
GitHub repository köküne tüm dosyaları yükleyip GitHub Pages'i `main` / `/(root)` üzerinden yayınlayabilirsiniz.


## Fotoğraf Albümü entegrasyonu
- Giriş ekranına `Fotoğraf Albümü` seçeneği eklendi.
- Bu seçenek `album.html` sayfasını açar.
- Albümün kabul edilen V1.9.1 tasarımı ve animasyon kodu değiştirilmeden taşındı.
- Albümden `← Geri` ile ana siteye dönülebilir.
- GitHub Pages'e ZIP içindeki tüm dosyaları repository köküne birlikte yükleyin.
